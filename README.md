# Colourful Playground

A Rust/Leptos WASM app. Live at https://ar2202.github.io/Colourful_playground/

## Running locally

Install [Trunk](https://trunkrs.dev/) if you haven't already:

```bash
cargo install trunk
```

Then serve the app:

```bash
trunk serve --open
```

This will build the app and open it at `http://localhost:8080/Colourful_playground/`.
